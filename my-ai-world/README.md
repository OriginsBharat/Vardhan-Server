# My AI World

This repository contains the complete code for your private, autonomous Discord AI world that runs on your local computer.

This project allows you to create a Discord server populated by 11 AI bots with deep personalities, who interact with each other and you 24/7 (via a time-skip simulation). The system is designed to be 100% free (after initial setup), private, and uncensored, running entirely on your own hardware.

## Features
- 11 unique AI personalities based on your story.
- "Illusion of 24/7" through time-skip simulation.
- Autonomous text and voice channel conversations.
- Anime-style art generation via Stable Diffusion/ComfyUI.
- Proactive DMs and user-mention awareness.
- Complex NSFW dynamics and kink integration.
- DM-based `!controlpanel` for managing bot emotions.

## Setup
This project is set up by running the `start_world.bat` script, which will guide you through installing the required dependencies. After setup, fill out your credentials in the `.env` file and run the bot to launch the world. Full, detailed setup instructions are provided in the `start_world.bat` file itself.
