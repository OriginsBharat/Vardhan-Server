Here is how you can easily use the voice from a YouTube video for Maya:

1.  **Find the YouTube video** with Tashi's voice that you like.
2.  **Use a free online "YouTube to WAV converter" website.** There are many available if you search for that term on Google.
3.  **Paste the YouTube video link** into the converter website.
4.  **Download the `.wav` file** that the website provides.
5.  **Rename that downloaded file to exactly `Maya.wav`**.
6.  After you run the `setup_world.bat` script, place that `Maya.wav` file into the `data/voices` folder that the script creates.

That is all. The system will then automatically use Tashi's voice for Maya. This gives you the ultimate flexibility to use any voice you can find on YouTube.
